# 茶叶品尝记录｜静儿茶馆｜鹿隐花间｜困鹿山18号｜2023年

## 当前结论

**个人适口度：7.5 / 10（用户自评）**  
**复购态度：可能回购**  
**证据充分度：中**

这款茶本次最突出的特点是：**甜度非常高、花香明显入水、苦能化甜、喉部回甘清楚。**

前段因为本次撬茶较碎，萃取速度明显偏快：在 **7g / 150ml、100℃、12秒 + 12秒合并** 时苦底被明显放大；缩短至 **5秒 + 5秒** 后，甜度、花香和回甘反而表现得更完整。由此看，本次“苦底明显”需要降权，不能直接作为产品固有缺陷。

进入中后段后，甜感仍然非常强，甚至出现一点“发齁”的感觉，但花香和层次感下降得更快，因此整体结构稍弱。耐泡性主要体现在**甜度和回甘持续**，并不等于香气与层次同样持续。

一句话记录：

> **甜度非常突出，花香明显入水，苦能化甜、喉部回甘清楚；辨识度高，但中后段香气与结构弱于甜感，后段略显发齁。**

### 当前结论

本次最有把握的判断不是“苦”，而是：

**甜度非常高，花香明确进入茶汤，苦能化甜，喉部回甘明显。**

本次碎茶使萃取曲线明显前移，在较长时间下苦感被放大，因此第一次品饮不能把“苦底重”直接定性为产品缺陷。真正找到适合本次碎度的 **5秒 + 5秒** 后，茶表现出较高辨识度：甜感非常突出，并有明确的水中花香和回甘。

短板也比较明确：中后段花香和层次下降得比甜感快，最后甜度依然很高，但结构支撑不足，出现略“齁”的感觉。因此它的耐泡主要体现为**甜和回甘持续**，而不是香气、汤体和层次持续同步。

以本次表现，**7.5 / 10，可能回购。**

## 冲泡参数演进

### 本次最佳参数

在本次“撬得较碎”的状态下：

- **7g / 150ml**
- **100℃**
- **5秒 + 5秒**
- 两泡彻底沥干后合并饮用
- 最好加茶滤，避免碎渣在公道杯或饮杯内继续浸泡

这组参数最能同时保留甜感、花香和回甘，并压低过度萃取造成的苦。

### 下次复饮建议

建议做一次**探索型复饮**，只改茶水比，同时尽量改善撬茶完整度：

- **7g / 175ml 左右（约1:25）**
- **100℃**
- 尽量撬成 **2–4块相对完整的薄片 / 小块**
- 前段从 **5–6秒** 起步
- 仍按两泡合并饮用
- 如有碎渣，使用茶滤

下次主要验证：

1. 1:25 后，今天的“齁甜”是否变得更清爽；
2. 水中花香能否保持；
3. 苦底是否明显下降，但回甘仍保留；
4. 更完整茶块下，中后段层次是否比本次更好；
5. 若甜度依然异常突出，则可确认“高甜”是产品稳定风格，而不是本次碎茶与高茶水比共同放大的结果。
