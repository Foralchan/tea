# 0. 研究目标

最初目标是建立一个能够容纳普洱生茶不同产区、微产区的二维风味坐标系，并逐步把研究从“易武、班章、冰岛”等大区，推进到：

- 同庆河 / 铜箐河
- 天门山
- 冷水河
- 白沙河
- 黑水梁子
- 白茶园 / 百茶园
- 哆依树
- 薄荷塘
- 章家三队
- 曼新龙
- 冰岛五寨
- 磨烈
- 正气塘
- 小荒田
- 大忠山
- 忙波
- 等村寨级、茶地级、微地块级对象。

研究的核心不是给每一个市场山头“贴口感标签”，而是：

1. 先确认**这个名字到底是什么地理层级**；
2. 再确认是否有**年份、季节、原料、工艺相对清楚的样品**；
3. 尽可能寻找**同年份、同制作者、同审评者、同冲泡参数**的横向样本；
4. 最后才决定是否进入坐标；
5. 如果地点本身不足以解释方差，就引入品系、树龄、栽培管理、工艺等控制变量。

# 1. 坐标模型的演化

## 1.1 初始模型

最初设想：

- X：强 ↔ 柔
- Y：甜 ↔ 苦
- 花香等作为附加维度

很快发现“甜”和“苦”并不是互斥关系：

- 老班章可以苦明显，同时汤中直接甜也明显；
- 老曼峨重苦样可以同时存在可辨认的汤甜；
- 磨烈、小荒田可以结构很强，同时直接甜很高；
- 苦后回甘和“入口直接甜”也不是同一个变量。

因此“甜—苦”不能作为同一轴两端。

## 1.2 第二版模型

改为：

- X：强 ↔ 柔
- Y：直接甜感
- 苦、涩、回甘独立记录

但“强”又混入两个不同概念：

- 口腔里的结构、硬度、张力
- 茶气 / 身体层面的体感

同庆河、坝歪等样品证明：
**汤可以很细柔，但茶气很强。**

因此继续拆分。

## 1.3 当前正式模型

### 主坐标

**X = 口腔结构张力 `structure_tension`**

从：

- 柔
- 松
- 舒展
- 细软
- 绵柔

到：

- 紧致
- 硬朗
- 有骨架
- 甘冽
- 冲击
- 口腔压力 / 饱和度高

**Y = 直接甜感 `direct_sweetness`**

只测：

- 第一口 / 汤中本身有没有清晰甜感
- 甜是不是直接存在于茶汤

不把以下内容混进 Y：

- 苦后回甘
- 喝完后的口腔甜
- 生津之后的甜
- 陈化形成的甜润感

### 独立连续指标

- `flavor_density`：有效滋味密度
- `bitterness`：苦强度
- `astringency`：涩强度
- `bitterness_decay`：苦化开速度
- `astringency_decay`：涩化开速度
- `huigan`：回甘
- `salivation`：生津
- `body_thickness`：汤体厚度
- `water_fineness`：水路细度
- `cooling`：清凉感
- `qi_body`：体感 / 茶气
- `aroma`：香型
- `wildness`：山野 / 森林感
- `entry_dominance`：
  - sweet-dominant
  - balanced
  - bitter-dominant
  - astringent-dominant

### 控制变量

- `year`
- `season`
- `tree_age_class`
- `cultivation_system`
- `cultivation_management`
- `raw_material_type`
- `processing_quality`
- `storage`
- `brewing`
- `reviewer_independence`
- `producer_independence`

# 2. 两层地图：真实饮用地图 vs Terroir 研究地图

研究过程中发现，必须区分两个问题。

## 2.1 Level 1｜真实饮用地图

回答：

> 市场上买到“这个名字”的茶，通常可能喝到什么风格？

允许纳入：

- 树龄不完全一致
- 栽培体系不同
- 品牌风格不同

但仍过滤明显工艺缺陷、仓储问题和冲泡失败。

## 2.2 Level 2｜Terroir 研究地图

回答：

> 尽量控制变量以后，这个地理单元本身可能稳定贡献什么差异？

要求尽量控制：

- 同季节
- 接近树龄 / 原料等级
- 接近加工体系
- 接近年份
- 尽可能多个独立制作者 / 审评者

例：

**章家三队**可以进入 Level 1 的右下象限，但其主要样本带明显台地 / 较年轻栽培体系混杂，不能直接与薄荷塘高杆古树在 Level 2 中作纯 terroir 比较。

# 3. 证据等级与纪律

## A 级
- 同行评议论文
- 政府行政区划
- 世界遗产 / 官方资源调查
- 标准化样品研究

## B 级
- 年份、季节、投茶量、器具、逐泡相对完整
- 制作者 / 品牌明确
- 地点相对清楚
- 最好有第二样品复现

## C 级
- 品牌商品页
- 茶媒体
- 茶山游记
- 单一样品且控制不足

## 地点证据与风味证据必须拆开

一个地方可以：

- 行政身份 A
- 风味样品 C

不能因为地点确定，就自动提高风味证据等级。

# 5. 西双版纳｜标准化样品与地点纠错

## 5.1 章朗

行政路径：

> 云南 → 西双版纳 → 勐海县 → 西定哈尼族布朗族乡 → 章朗村

地理粒度：

- 行政村级古茶区
- **行政上不属于布朗山乡**

标准化样品：

- 2022
- 统一条件加工晒青毛茶
- Foods 2026 标准化研究 H1

主要表现：

- 花果香相对强
- 有涩
- 醇和 / 后甜
- 直接甜不够明确

当前：

- `coordinate_status = hold`
- 香气与涩比直接甜更可靠

---

## 5.2 曼糯

不能当作单一行政村风味点。

更合理结构：

> 勐海县 → 勐往乡 → 曼糯古茶园区域  
> 覆盖曼糯大寨、中寨、上寨

至少曼糯大寨可钉：

> 勐往乡 → 勐往村 → 曼糯大寨村民小组

标准化样品 H2：

- 弱花果香
- 醇厚
- 涩

具体样品又可出现：

- 花果甜香
- 苦涩明显
- 甘冽劲爽
- 生津回甘持续

结论：

- 曼糯应为父节点
- 后续拆大寨 / 中寨 / 上寨
- 不能直接给整个曼糯一个单点

---

## 5.3 景洪勐宋

必须与勐海勐宋拆开。

行政：

> 景洪市 → 勐龙镇 → 勐宋村

不是：

> 勐海县 → 勐宋乡

Foods 2026 J2：

- 弱果香
- 浓 / 厚
- 涩

官方资料：

- 勐宋村下辖约 12 个自然村
- 古茶园面积大

结论：

- “景洪勐宋”粒度仍偏粗
- 需要继续拆自然村
- 不能混入那卡、保塘、蚌龙等勐海勐宋资料

---

## 5.4 蚌龙

原清单“邦龙”应标准化为：

> **蚌龙**

行政：

> 勐海县 → 勐宋乡 → 蚌龙村

`邦龙 / Banglong` 作为 alias。

Foods 2026 H6：

- 弱花果香
- 较醇和
- 涩
- 直接甜未见强证据

当前：

- 地点身份通过
- 风味样品不足
- `coordinate_status = hold`

# 6. 景迈山体系

## 6.1 世界遗产九个传统村落

九村：

1. 芒埂
2. 勐本
3. 景迈大寨
4. 糯岗 / 糯干
5. 芒景上寨
6. 芒景下寨
7. 芒洪
8. 翁基
9. 翁洼

景迈山结构：

- 5 片古茶林
- 9 个传统村落

### 重要纠错

**大平掌不是传统村落，而是一片古茶林。**

不能：

> 大平掌 = 景迈一个村

更不能：

> 大平掌 = 整个景迈山

---

## 6.2 五片古茶林与村落关系

- 芒埂 + 勐本 → 芒埂—勐本古茶林
- 景迈大寨 → 景迈大寨古茶林
- 大平掌 → 独立古茶林，位于景迈大寨以南
- 糯岗 → 糯岗古茶林
- 芒景上寨 + 芒景下寨 + 芒洪 → 芒景上下寨—芒洪古茶林
- 翁基 + 翁洼 → 翁基—翁洼古茶林

---

## 6.3 云南农业大学 2024 七村寨标准样品

采样：

- 2022 年 4–5 月春茶季
- 一芽两叶
- 晒青毛茶
- 统一专业审评

七个样点：

- 芒景上寨
- 帮改
- 翁基
- 新酒房
- 勐本
- 芒埂
- 芒景下寨

与 UNESCO 九村重合的五个：

- 芒埂
- 勐本
- 芒景上寨
- 芒景下寨
- 翁基

香气 / 滋味评分中：

- 芒埂香气突出
- 翁基综合高
- 勐本滋味较高
- 芒景下寨是七样中唯一没有检测到花香型特征物质的样本之一

### 重要结论

不能写：

> 景迈各寨 = 兰花香

不同村寨芳香物质组合存在差异。

# 7. 临翔区｜第一版封版

## 7.1 官方结构纠错：不是“昔归 + 三个区”，而是“一芽、四区、七山”

临翔区当前产业框架应记录为：

```text
临翔区茶产业框架
│
├─ 一芽
│  └─ 马台芽茶
│
├─ 四区
│  ├─ 坡脚产区（南美坡脚）
│  ├─ 曼毫产区（蚂蚁堆曼毫）
│  ├─ 晓光山产区（当前产业口径：凤翔昔本）
│  └─ 冰赛产区
│
└─ 七山｜昔归七山
   ├─ 忙麓山
   ├─ 那罕
   ├─ 曼岗
   ├─ 草籽地
   ├─ 昔归绿水塘
   ├─ 昔归老街子
   └─ 丫口
```

关键纠错：

- “四区”与“七山”是并列的产业 / 茶区分类；
- 不能写成 `昔归 → 曼毫 / 晓光山 / 冰赛`；
- “昔归七山”本身也不是行政树，而是将不同地理粒度并列起来的茶产业分组。

核心官方来源：临翔区 2026 年政府工作报告与区级产业部门资料。

---

## 7.2 四区地点层

### 坡脚

行政路径：

> 临翔区 → 南美乡 → 坡脚村

当前定义：

```yaml
geo_identity: administrative_village + tea_area
location_confidence: A
coordinate_status: HOLD
```

2026 头春样品支持：花果香高、浓度高、醇厚顺滑、水感细、汤体饱满、回甘生津强。

但现有可用样品没有足够清楚地区分“汤中直接甜”与“回甘甜”，也没有把结构张力讲清，因此不能为 X / Y 正式赋值。

结论：**地点成立，风味待真正可审计样品；停止用低质量网页堆形容词。**

### 曼毫

行政路径：

> 临翔区 → 蚂蚁堆乡 → 曼毫村

官方产业身份稳定，且当地茶产业规模不小；但公开网络仍缺：

- 近年春茶；
- 原料层级清楚；
- 完整逐泡；
- 可用于 X / Y 的感官记录。

因此：

```yaml
location_confidence: A
flavor_evidence: insufficient
coordinate_status: HOLD
```

### 晓光山

当前优先挂载：

> 临翔区 → 凤翔街道 → 昔本村 → 晓光山古茶园 / 晓光山产区

但必须保留地点冲突：2024 年官方产业部门明确使用“凤翔昔本”，同年另一份官方转载宣传材料仍出现“圈内晓光山”。

因此：

```yaml
current_official_preference: 凤翔街道 / 昔本村
conflicting_or_historical_usage:
  - 圈内晓光山
conflict_flag: true
```

长期契作样品体系对风味的描述较稳定：

- 樟香、兰香高扬；
- 入口鲜爽、甜醇；
- 微涩即化；
- 生津明显；
- 汤体中高；
- 喉韵较深。

当前：

```yaml
x_structure_tension: low_mid_to_mid
y_direct_sweetness: high
aroma: very_high
coordinate_status: provisional
flavor_confidence: B-
```

来源独立性不足，因此不升级。

### 冰赛

现行官方产业定义：

```text
冰赛产区
├─ 圈内乡
│  ├─ 昆赛村
│  └─ 细博村
├─ 博尚镇
│  └─ 那招村
└─ 平村乡
   └─ 那玉村
```

它是跨 3 个乡镇级单位、4 个行政村的产业茶区，父节点不能作为 terroir 单点。

更早官方资料直接出现“圈内昆赛‘冰赛’古茶园”，说明昆赛是最强的历史 / 生产核心锚点。进一步发现：临翔区冰赛茶叶种植农民专业合作社注册地址在昆赛村忙定组，但这只能证明生产组织锚点，**不能证明冰赛古茶园本身就在忙定组**。

当前模型：

```yaml
冰赛产区:
  type: cross_village_industry_tea_area
  coordinate_eligible: false
  flavor_generalization_allowed: false

  core_anchor:
    昆赛:
      historical_production_anchor: strong
      忙定组:
        relation: production_organization_anchor
        ancient_tea_garden_location: unverified

  constituents:
    昆赛: HOLD
    细博: PARTIAL/HOLD
    那招: HOLD
    那玉: HOLD
```

细博目前有一份“大树春茶”具体记录，可确认：苦轻、涩弱、鲜润、回甘呈淡淡清甜；但它没有证明“直接甜高”，也没有证明结构柔，因此仍 HOLD。

“冰赛像冰岛 / 冰岛式甜柔”只保留为历史市场假说，不作为主数据库风味事实。

## 7.3 昔归七山：产业分组与行政树必须分离

现行“七山”：

1. 忙麓山
2. 那罕
3. 曼岗
4. 草籽地
5. 昔归绿水塘
6. 昔归老街子
7. 丫口

已能钉死的行政关系：

```text
邦东乡
├─ 邦东村
│  └─ 昔归自然村
│     └─ 忙麓山
│
├─ 曼岗村
│  ├─ 曼岗茶区
│  └─ 那罕组 / 那罕寨
│
└─ 和平村
   └─ 丫口寨
```

未钉死到村委会的仍为：

- 草籽地
- 昔归绿水塘
- 昔归老街子

处理原则：**官方“七山”身份可以确认，但不要为了补树而猜行政父级。**

粒度差异：

- 曼岗：行政村 + 茶区
- 那罕：曼岗村下面的组 / 寨级微产区
- 丫口：和平村下面的寨
- 忙麓山：山体 / 核心古茶园微产区

# 15. 左下象限搜索

目标：

> 柔、刺激低，但直接甜也弱。

结果：

**目前没有找到足够干净的稳定微产区代表。**

尝试样本：

- 困鹿山 2023 单株
- 无量山匿名 1 / 3 号地 2022
- 南糯山多依寨 2026
- 半坡老寨
- 那卡 2023
- 落水洞 2021

共同发现：

- 很柔
- 很薄
- 很淡
- 苦涩低
- 滋味不丰富

都不必然等于“不甜”。

例如：

- 困鹿山柔、淡、轻，但入口甘甜
- 无量山匿名地块汤薄、力度低，但直接甜明确
- 落水洞转化期平淡，但仍甘甜柔顺

### 阶段结论

在工艺正常的春季生普样本中：

> **柔与直接甜可能存在一定正相关。**

至少“左下”不是一个容易由稳定 terroir 产生的常见象限。

左下更可能来自：

1. 原料本身很弱 / 萃取物少
2. 工艺破坏甜感
3. 冲泡不足

这些都不适合作为产区风格。

因此目前左下应保持空白，不强填。

# 32. 勐库第一版区域结论

被否定的粗概括：

## “西半山甜、东半山苦”

过粗。

正气塘是明确反例。

## “冰岛体系才甜”

不成立。

磨烈、小荒田、正气塘、大忠山都能有明显汤中直接甜。

## “勐库强茶就是苦涩重”

不成立。

磨烈、小荒田可“强＋甜”；大忠山可“低苦＋有结构”。

更好的总结：

> **勐库很多优质春茶都明显甜，真正的差异是“甜被什么样的结构承载”。**

- 冰岛老寨：细甜
- 南迫：香甜
- 地界：有重量的甜
- 坝歪：柔汤 + 强体感
- 小户赛：高香细甜
- 大户赛：绵密厚甜
- 正气塘：温润直接甜
- 大忠山：高甜 + 锐 / 爽结构
- 磨烈：甘冽、有骨架的强甜
- 小荒田：硬、开阔、外放的强甜
- 懂过：爽朗浓醇，直接甜退居次位、回甘结构更突出
- 坝糯：甜与鲜爽倾向稳定，但结构 / 苦涩方差较大

## 34.13 亚练藤子茶与新保护茶园

> **亚练藤子茶是“种质 × 树姿 × 传统采养方式”高度纠缠的地方茶类型。**

- 独立遗传品种；
- 单纯藤条采养；
- 单纯自然杂交群体。

## 37.1 地点本身不够，必须识别原料种群

- 中小叶型 / 其他地方类型
- 混合 / 未知

如果不保存这一层信息，很容易把“种群 / 栽培体系差异”误判为 terroir。

## 37.2 “永德大雪山”不能把风味向下继承

市场上“大雪山茶”的浓强、蜜香、苦底、强气等描述，只能证明**市场标签下存在某种风格**；不能证明忙肺、曼来、放牛场都天然如此。

## 37.3 地方茶类型可能同时混合遗传、树姿与采养

亚练藤子茶提醒：不要过早把一个地方名词硬拆成“品种”或“管理方式”。白莺山进入后必须继续保持这种克制。

## 37.4 旧“代表性古茶园清单”不能替代官方资源树

2026 第四批古茶园保护范围给出大量村寨 / 茶园级官方单元，证明永德微产区比旧“十二古茶园”体系复杂得多。

# 38. v2 阶段的全貌

到本版为止，研究已经从最初的“山头风味表”变成三层结构：

### 第一层｜地点实体

先判断一个名字究竟是：

- 行政村 / 自然村 / 村民组
- 山体
- 古茶林 / 古茶园
- 茶区 / 核心区
- 跨村产业区
- 生态父节点
- 市场名 / 公共品牌

### 第二层｜样品与控制变量

至少考虑：

- 年份 / 季节
- 树龄 / 原料等级
- 栽培 / 野生属性
- 地方群体 / 品系 / 原料种群
- 采养方式
- 加工质量
- 仓储
- 制作者 / 审评者独立性

### 第三层｜风味

主研究坐标仍保持：

> **X = 口腔结构张力**  
> **Y = 汤中直接甜感**

苦、涩、回甘、生津、汤厚、水路、清凉、qi/body、wildness、香型继续作为独立维度。

# 39. 当前最核心的方法结论｜v2

1. **口腔结构张力**已跨易武、勐海、勐库、临翔、永德重复显示出较强区分力。
2. **直接甜感**仍有区分力，但大量优质春茶集中在 Y 轴上半区是样本现实，不是模型失败。
3. 苦与甜不是一条轴两端；忙肺、那罕都可以苦甜并存。
4. 回甘甜不等于直接甜；细博是很好的反例。
5. 汤柔与气弱不是一回事；丫口直接证明这一点。
6. 岩韵与结构硬不是一回事；曼岗直接证明这一点。
7. 山野气 / wildness 强也不等于汤粗硬；草籽地支持这一点。
8. 汤厚不等于结构强；坡脚、放牛场等节点继续要求分开记录。
9. 官方产业区不能自动获得风味坐标；冰赛是最清楚的例子。
10. 茶产业分组不能污染行政树；昔归七山、冰岛五寨、班章五寨都需要茶区关系与行政关系分开。
11. 商品父标签不能向子节点继承风味；永德大雪山尤其如此。
12. 地点本身可能不足以解释差异，原料种群 / 品系 / 野生栽培属性必须成为控制变量。
13. 如果样品存在明显工艺混杂，即使风味方向再“漂亮”也应 HOLD；昔归绿水塘是当前范例。
14. 如果没有合格样品，“不知道”就是正确结果；曼毫、昆赛、那招、那玉都保留空白。
15. 如果一个父级内部已经出现稳定差异，应继续往自然村 / 茶地拆，而不是平均成一个山头味道。

# 40. 白莺山｜第一版封版

白莺山这一阶段最重要的结论，不是得到一个“白莺山味”，而是确认：

> **在白莺山，同一个地理茶区内部的地方茶树类型 / 遗传背景本身就是一级解释变量。**

因此白莺山暂时**没有任何一个地方茶树类型进入 PROVISIONAL 主坐标**。这不是研究失败，而是说明必须先控制材料身份，再讨论 terroir。

---

## 40.1 三种不同空间口径必须拆开

当前公开资料至少存在三个不同尺度：

### A｜白莺山宽口径茶区

较新的地方资料把白莺山茶区描述为：

- 以白莺山村为核心；
- 覆盖漫湾镇、茂兰镇、忙怀乡三个乡镇；
- 约 25 个行政村；
- 总面积约 5.6 万亩；
- 其中高海拔古茶园规模约 3 万亩。

建议：

```yaml
白莺山茶区:
  geo_type: cross_township_tea_region
  coordinate_eligible: false
```

### B｜第一批白莺山栽培型古茶园保护体系

较早保护资料主要锚定：

> **白莺山村 + 核桃林村，共约 25 个村民小组，约 1.24 万亩古茶园。**

建议：

```yaml
白莺山古茶园保护体系:
  geo_type: protected_ancient_tea_garden_complex
  coordinate_eligible: false_as_parent
```

### C｜“茶树演化自然博物馆”核心展示 / 研究空间

部分较新的宣传 / 实地资料又使用白莺山、密竹林、核桃林、新村、酒房等行政村作为“博物馆”展示范围。

当前不强制与 A、B 两种边界合并。

> **产业茶区、古茶园保护范围、博物馆/展示范围不是同一个地理概念。**

---

## 40.2 白莺山村内部已经钉住的关键节点

第一版可用树：

```text
云县
└─ 漫湾镇
   ├─ 白莺山村
   │  ├─ 熊家自然村
   │  │  └─ 二嘎子茶王
   │  ├─ 核桃箐组
   │  │  └─ 白芽子茶王
   │  ├─ 茶家组
   │  │  └─ 本山茶王
   │  ├─ 中村组
   │  │  └─ 黑条子茶王
   │  └─ 中山茶树小组？
   │     [现有实地记录，行政身份待独立核]
   │
   └─ 核桃林村
      └─ 村组 / 茶园继续保留发现池
```

强制消歧：

- **核桃箐组 ≠ 核桃林村**；
- “中山茶树小组”不能因为名称相近就自动并入“中村组”；
- 某类茶王树位于某村组，只证明代表性单株位置，**不能反推整个村组只生产该类型**。

白莺山茶园长期存在多个地方类型近距离混生，因此：

> `熊家 = 二嘎子 terroir`、`中村 = 黑条子 terroir` 这类写法均禁止。

---

## 40.3 “本山、二嘎子、黑条子”等首先是地方茶树类型，不是已钉死的 cultivar

2014 年对白莺山 12 类茶树资源的形态 / 叶片解剖研究，以及后续 SSR / EST-SSR 群体遗传研究共同说明：

- 白莺山同时存在大理茶 `Camellia taliensis`；
- 存在阿萨姆茶 / 云南大叶栽培背景；
- 存在大量中间表型、杂交 / 渐渗背景；
- 多个地方类型之间存在基因交流；
- 12 个民间 / 地方类型名称不等于 12 个彼此封闭的现代栽培品种。

因此正式字段优先：

```yaml
local_tea_type:
```

而不是默认：

```yaml
cultivar:
```

### 12 类目录本身存在版本差异

2014 学术目录中出现“勐库小叶茶”；较新的地方资料则出现“秃房茶”而不列“勐库小叶茶”。

因此建议保存：

```yaml
local_type_catalog:
  source:
  year:
  catalog_scope:
  types:
```

不要建立唯一、永远固定的“白莺山十二品种表”。

---

## 40.4 四个核心类型｜当前感官结果

### 本山茶

第一组同场晒青品饮指向：

- 汤较厚 / 爽滑；
- 山野感强；
- 苦涩极低。

但 2024 本山紫芽独立样又出现：

- 第一泡可感直接甜；
- 花香 / 蜜香；
- 涩很低；
- 汤体反而偏轻、偏薄。

所以当前最稳定的不是“厚”，而是：

> **低苦涩 + 野韵明显 + 可以出现直接甜。**

```yaml
本山:
  direct_sweetness: mid_to_high?
  bitterness: very_low_to_low
  astringency: very_low
  wildness: high_to_very_high
  body_thickness: high_variance
  structure_tension: unknown
  coordinate_status: HOLD
```

### 二嘎子

较稳定方向：

- 兰香明显；
- 轻苦 / 轻涩；
- 回甘、生津持久；
- 山野感明显。

著名茶王单株可表现得极柔、极低苦涩，但**单株不代表地方类型均值**。

```yaml
二嘎子:
  direct_sweetness: unknown_to_high?
  structure_tension: unknown_to_mid?
  bitterness: low
  astringency: low_mid
  huigan: high
  salivation: high
  aroma: orchid_high
  coordinate_status: HOLD
```

### 黑条子

目前多组资料仍与二嘎子高度重叠：

- 兰香；
- 轻苦涩；
- 回甘、生津；
- 山野感。

现阶段最有价值的结果反而是：

> **黑条子 ≈ 二嘎子，未证明二者必须在主图上强行拉开。**

```yaml
黑条子:
  coordinate_status: HOLD
  sensory_overlap_with_二嘎子: high
```

### 白莺山勐库大叶种

同场比较和独立实地记录都支持：

- 花香 / 百花香高；
- 蜜甜倾向；
- 挂杯香持久；
- 第一组中汤体相对本山偏薄。

更重要的是，较新的实地资料显示：

> **勐库大叶种长期是白莺山实际生产中的大宗主体。**

因此商品只写“白莺山古树茶”时，不能默认是本山 / 二嘎子等稀有地方类型。

```yaml
白莺山勐库大叶种:
  aroma: very_high_floral
  direct_sweetness: high?
  body_thickness: low_mid_to_mid?
  structure_tension: unknown
  coordinate_status: HOLD
```

---

## 40.5 五个“异常端点”｜材料空间比主坐标更有价值

### 红芽口 / 红芽茶

2014 形态学研究中单独形成 II-c；后期资料记录毛茶：

- 滋味淡；
- 苦味重；
- 产量低。

但没有找到符合门槛的现代春茶逐泡样。

```yaml
红芽口:
  bitterness_hypothesis: high
  flavor_density_hypothesis: low_to_mid
  direct_sweetness: unknown
  structure_tension: unknown
  coordinate_status: HOLD
  future_sampling_priority: very_high
```

如果未来复现“淡而苦”，它将成为非常重要的反例：

> **高苦 ≠ 高密度 ≠ 高结构。**

### 柳叶茶

材料检测端极高：

- 茶多酚高；
- 水浸出物高；
- 儿茶素高；
- 地方资料称非常耐泡。

但没有现代可审计晒青样。

```yaml
柳叶:
  biochemical_potential: high
  durability_claim: high
  bitterness: unknown
  direct_sweetness: unknown
  structure_tension: unknown
  coordinate_status: HOLD
```

### 藤子茶

2014 学术研究直接把“藤子茶”作为白莺山地方茶树类型；后期资料出现“藤条茶”写法。

现有资源性状描述存在：

- 多酚并不低；
- 毛茶滋味淡；
- 不耐泡。

但同样没有合格现代晒青样。

```yaml
白莺山藤子茶:
  canonical_local_type: 藤子茶
  aliases_or_later_usage:
    - 藤条茶
  name_conflict_flag: true
  do_not_infer: 藤条采养方式
  coordinate_status: HOLD
```

**不要与永德亚练“藤子 / 藤条”跨地区自动归一。**

### 白芽子

稳定的是资源 / 形态描述：

- 芽白、茸毫显；
- 叶张偏薄；
- 数量稀少；
- 不耐泡声明。

缺现代完整感官样，HOLD。

### 大叶本山白芽口

2014 聚类更靠近本山 / 二嘎子 / 黑条子这一大类，当前更适合作为**材料连续谱的桥接类型**，而不是强行寻找一个极端风味。

## 40.6 白莺山最终状态

### PROVISIONAL

**无。**

### HOLD｜有一定感官观察

- 本山
- 二嘎子
- 黑条子
- 勐库大叶种

### HOLD｜资源 / 材料性质很有价值，但现代感官样不足

- 红芽口
- 柳叶
- 藤子
- 白芽子
- 大叶本山白芽口

### 父级，不坐标

- 白莺山宽口径茶区
- 白莺山古茶园保护体系
- 白莺山村作为未控制地方类型时的平均风味点

### 白莺山对方法的正式贡献

1. **地方茶树类型 / 遗传背景可以是一级解释变量。**
2. `wildness` 不等于 `structure_tension`；本山可能很野但低苦涩。
3. 同一 local type 内部仍可能有明显单株表型 / 树龄 / 制作方差。
4. 化学含量不能直接生成 X/Y、苦味、汤厚或耐泡分数。
5. 单株茶王不能代表地方类型平均值。
6. “白莺山古树茶”商品名不能自动映射到稀有地方茶树类型。
7. 当材料身份未控制时，“白莺山 terroir 是什么味”这个问题本身可能问错了。

# 41. 凤庆｜一次性收束

凤庆的核心特征是：

> **古茶资源极丰富，但公开、可审计的生普 / 晒青样品密度明显低于资源密度。**

# 46. v3 阶段的总体方法结论

在 v2 的基础上新增 / 强化：

1. **地方茶树类型 / 遗传背景是潜在一级解释变量。**白莺山把这一点正式推到研究核心。
2. `local_tea_type` 不应自动写成严格 `cultivar`。
3. 化学成分、茶多酚、水浸出物不能直接转换成苦、汤厚、耐泡或 X/Y。
4. 单株茶王不能代表地方类型或村寨均值。
5. 区域公共品牌必须与真实 terroir 节点拆分；镇康马鞍山茶是最新范例。
6. 现代产业茶区不能自动当古树微产区点；勐撒是最新范例。
7. 古茶资源丰富不等于生普风味证据丰富；凤庆是最新范例。
8. 同名地点必须保留行政冲突，不得按市场语境自动合并；镇康两个“马鞍山”是最新范例。
9. 一个区域 first-pass complete 的标准不是“每个名字都有坐标”，而是**重要名字都已有明确的数据状态与为什么不能坐标的原因**。

# 48. 普洱市｜总体结构与本轮方法修正

普洱市这一轮进一步证明，县级“名山清单”通常同时混合了四种不同对象：

- 历史古茶资源区；
- 当代产业茶区 / 公共品牌；
- 真实行政村 / 村民小组；
- 可以直接作为 Level 2 terroir 的小茶园 / 微地块。

因此 v4 对 `origin_microregion` 增加 / 强化以下关系：

```yaml
legacy_tea_geography_group:
current_industry_group:
resource_registration_layer:
raw_material_type:
local_tea_type:
cultivation_management:
processing_identity:
```

其中最重要的新纪律有五条：

1. **产业“八大茶区 / 六大古茶山 / 无量八部”不能自动成为行政父节点。**
2. **野生茶树群落与商品栽培古茶必须拆开。**
3. **同一个地点内部若存在叶型 / 地方材料显著差异，坐标应挂到材料特定样，而不是地点平均。**
4. **白茶、红茶等加工形成的甜香不能反推同产地晒青生普。** 景谷是最典型案例。
5. **现代品牌外扩会污染古树产地名。** 老安寨、上牛圈、迷帝等都出现了“同名不同原料层”的风险。

# 59. v4 阶段的总体方法升级

在西双版纳、临沧、普洱市三大核心区域跑完后，研究对象已经明确从：

> 山头名称

升级为：

> **地点实体 × 茶树材料 × 栽培/采养管理 × 原料层级 × 加工身份 × 样品年份与冲泡 × 风味结构**

必须长期坚持的规则：

1. **父区不继承子区风味。**
2. **区域品牌不等于地理父级。**
3. **野生茶资源默认不进入商品生普地图。**
4. **古树年龄宣传不当科学测年。**
5. **藤条 / 高杆首先记录为树型或管理，不自动当 cultivar。**
6. **地方茶树类型先用 `local_tea_type`，有可靠遗传 / 登记证据再升级 cultivar。**
7. **同一个地点若材料多样，允许一个地点拥有多个 material-specific 坐标。**
8. **白茶 / 红茶加工的甜香数据不得用于同产地生普 Y。**
9. **“苦后回甘甜”仍不能写成 `direct_sweetness = high`。**
10. **first-pass complete 不要求全地图有点，而要求所有重要节点有明确状态。**

# 60. 下一阶段｜保山，以及全云南还缺什么

## 60.1 下一主区域：保山

保山应该是下一块正式系统研究对象。

原因不是“传统四大茶区”这个市场标签，而是古茶资源量本身足够大，并且结构清楚：

- 保山市级古茶树资源覆盖昌宁、隆阳、龙陵、腾冲、施甸；
- 昌宁占绝对主体；
- 昌宁当前已有漭水、温泉等多个古树茶主产区；
- 黄家寨、茶山河、联席、石佛山等已经具备可以继续下钻的真实古茶树群落。

建议保山顺序：

> **昌宁 → 腾冲 → 隆阳 / 龙陵 → 施甸快速扫尾。**

昌宁内部优先：

> **漭水黄家寨 → 茶山河 → 河尾老寨子 → 温泉联席 / 芭蕉林 → 田园石佛山**

第一轮先解决：

- 古茶资源层 vs 昌宁红茶品牌层；
- 大理茶 / 普洱茶等材料差异；
- 晒青生普是否有足够独立样，而不是被红茶数据污染。

## 60.2 保山之后还不能结束

如果目标是“云南生普地理尽可能完整”，官方古茶资源口径显示，古茶树主要分布在 9 个州（市）：

- 西双版纳（已完成）
- 临沧（已完成）
- 普洱（已完成）
- **保山（下一步）**
- **大理**
- **德宏**
- **楚雄**
- **红河**
- **文山**

因此保山之后建议分两档：

### 第二梯队｜需要真正系统研究

1. **大理**：重点南涧无量山体系，同时检查永平等古茶资源县；必须防止白茶产业加工风味污染生普数据。
2. **德宏**：芒市、梁河等古茶资源数量可观，且已有普洱茶加工实践，值得完整 discovery → first-pass。

### 第三梯队｜边缘古茶区 quick first-pass

3. **楚雄**
4. **红河**
5. **文山**

目标不是强造“名山”，而是判断是否存在：

> `真实栽培古茶 + 晒青生普 + 可追溯微区 + 足够风味证据`

若没有，就保留资源层而不进入坐标。

## 60.3 昆明 / 玉溪怎么处理

普洱茶地理标志保护范围一共包含 11 个州（市），除上述 9 个主要古茶资源州市外还包含：

- 昆明
- 玉溪

但现有省级古茶资源总体口径并未把二者列为主要古茶树集中分布州市，因此当前不值得像保山 / 大理 / 德宏一样深挖。

建议在全云南收尾时做一次：

```yaml
昆明: GI_edge_scan
玉溪: GI_edge_scan
```

只判断是否存在遗漏的生普 terroir 级古茶点。

## 60.4 云南之外

如果本项目严格以 GB/T 22111 的“普洱茶 / 生茶”地理标志范围为边界，那么怒江、丽江、昭通、迪庆等不属于当前普洱茶地理标志保护区，不需要为了“云南所有茶树”而纳入主地图。

如果未来项目另开“滇西 / 滇西北晒青茶”研究，则可以作为另一张地图，不应污染本项目的普洱生茶定义。

# 62. v5-full 增补说明｜从“三大核心区阶段总档”升级为“云南全部总档”

- 西双版纳、临沧、普洱市的完整地点树；
- 早期样品风味证据与坐标推导；
- 已确认的命名纠错；
- 已否定的假设；
- 方法从“山头风味”向“地点实体 × 样品控制变量 × 风味结构”的升级过程。

v5-full 不把这些历史研究“重新总结掉”，而是在其上继续增加四个强制变量：

```yaml
material_identity:
  description: 茶树材料 / 地方茶树类型 / 植物分类身份

puer_GI_status:
  values: [eligible, ineligible, conflict, unknown]
  description: 具体 origin node 是否位于现行普洱茶地理标志保护范围

processing_ecology:
  description: 同一地点的主导加工生态，区分生普/晒青、红茶、白茶、绿茶、民族发酵茶等

ancient_tree_count_basis:
  values:
    - formal_resource_census
    - government_feature_article
    - local_industry_count
    - producer_count
    - historical_estimate
  rule: 不同口径禁止直接相加或互相覆盖
```

因此当前研究对象正式写为：

> **地点实体 × 茶树材料 × 栽培 / 采养管理 × 原料层级 × GI 资格 × 加工身份 × 样品年份与冲泡 × 风味结构**

这一升级不是方法论装饰，而是在保山、麻栗坡、新平、德宏等地被实际资料反复逼出来的。

# 80. v5-full 全项目新增方法规则

## 80.1 地点不能继承子节点风味

父区、区域公共品牌、茶旅产业区均不得自动继承子微区风味。

典型：

- 无量山藏茶谷；
- 无量山樱花谷；
- 兔乐之；
- 回龙茶；
- 镇康马鞍山区域品牌；
- 冰赛；
- 六大茶山 / 九大古茶园总称。

## 80.2 material-specific coordinate

同一地点若存在多种茶树材料，允许未来拥有多个 material-specific 坐标。

典型：

- 龙陵绕廊麦子地；
- 昌宁联席 / 芭蕉林；
- 南涧回龙山；
- 新平峨毛；
- 双柏鄂嘉。

## 80.3 processing ecology

同一地点可能被多种加工传统分流：

- 昌宁 / 永平：红茶；
- 南涧：白茶、乌龙；
- 芒市：德昂酸茶；
- 红河：绿茶、白茶、晒红；
- 广南底圩：竹筒姑娘茶。

因此“网上风味共识”在这些区域尤其危险。

## 80.4 GI status 必须下沉到 origin node

县在 GI 内，不代表全县每个乡镇都在；地点在 GI 内，也不代表所有植物材料都符合普洱原料定义。

典型：

- 麻栗坡：古茶资源乡镇与 GI 乡镇不重合；
- 新平：者竜 / 平掌与水塘的差异；
- 马关古林箐：地点 GI 合格，但材料资格仍需逐材料判断。

## 80.5 古树数量必须带口径

以后所有古茶树数量至少附：

```yaml
count_basis:
count_year:
count_definition:
source_level:
```

禁止把“产业古树”“挂牌古茶树”“百年以上古茶树”“全部古茶树资源”直接相加。

# 82. 当前坐标纪律｜不要因为全省 first-pass 完成就扩点

本轮边缘区域几乎没有新增可直接画入主图的 PROVISIONAL X/Y。

必须保留这条结论：

> **地图完整度不等于点位数量。**

一个地区被完整研究，可能得到的最正确结论就是：

```yaml
coordinate_status: HOLD
```

原因可以是：

- 地点太粗；
- 材料未拆；
- 加工污染；
- GI 不合格；
- 生普样品不存在 / 不可审计；
- X / Y 关键维度缺失；
- 只有回甘，没有入口直接甜；
- 只有“柔滑”，没有结构张力证据。

# 83. v5-full 最终总裁决

云南全省第一轮之后，研究已经从“云南有哪些名山头”完全转型为一个可用于后续数据库 / HTML 的证据系统：

```text
地点实体
×
材料身份
×
栽培 / 采养
×
原料层级
×
GI 资格
×
加工生态
×
具体样品
×
冲泡条件
×
风味结构
```

主坐标仍保持：

> **X = 口腔结构张力**
>
> **Y = 汤中直接甜感**

独立维度继续保持：

- 苦；
- 涩；
- 回甘；
- 生津；
- 汤厚；
- 滋味密度；
- 水路；
- 清凉；
- qi / body；
- 香气；
- wildness；
- entry dominance。

第一轮版图研究到此封板。下一阶段应优先：

1. 清洗 `origin_microregion`；
2. 把所有 `PROVISIONAL / INTERVAL / HOLD / EXCLUDE` 状态结构化；
3. 建立可直接驱动 HTML 的 master dataset；
4. 用高信息增益真样而不是更多网页风味描述来升级 HOLD。
